#### 2.3.2 재편성 원칙

- 인원 균형: 총 21명을 A조 11명, B조 10명으로 나눕니다. 신규 2명이 A조에 배정되므로 A조가 한 명 많습니다.
- 마을 분산: 같은 마을 부목자가 한 조에 몰리지 않게 배치합니다. A조는 211 1명, 212 2명, 213 1명, 214 3명, 215 2명, 마을 미확인 2명이고, B조는 211 1명, 212 2명, 213 2명, 214 3명, 215 2명입니다.
- 실참여 분산: 참석이 불규칙한 인원(홍성일A 가족 간병, 김대연A 주일 격주 근무)이 한 조에 겹치지 않도록 홍성일A를 B조로 옮겼습니다. 이제 A조는 김대연A 1명, B조는 홍성일A 1명입니다.
- 기존 소속 유지: 위 여섯 건 외에는 기존 조 소속을 그대로 두어 변경 폭을 최소화했습니다.

### 2.4 특이사항

- 홍성일A 부목자는 가족 간병으로 현장 예배 참석이 어려웠고 연락 두절 이력이 있습니다(2026-05). 편성에는 유지하되 실참여는 별도 관리합니다.
- 김대연A 부목자는 주일 격주 근무로 부담을 표한 이력이 있습니다. 2026-08부터 B조 부조장에서 A조 조원으로 이동했으며 2026-09 재편성에서도 A조를 유지합니다.
- 편성표 표기 장페남은 기존 명단 기준 장쾌남으로 처리했습니다(인쇄 표기 확인 필요).
- B조 부조장은 2026-08부터 공석입니다. 메시지에 직책을 표기하지 않으므로 주간 알림에는 영향이 없으나, 내부 관리를 위해 임명 여부를 정할 필요가 있습니다.
- 이경모, 문형식 부목자의 소속 마을이 확인되면 2.3 편성표와 3.3 마을별 명단의 마을 표기를 함께 갱신합니다.

### 2.5 식당봉사 알림 메시지 형식 (2026-07 변경: 직책 미표기, 이름만 나열)

정조장, 부조장 직책 표기를 제거하고 전원 이름만 나열합니다. 직책은 내부 관리용으로만 유지합니다.

```
[식당봉사 알림] 09/13

이번주 식당봉사는 B조입니다.

정정진, 김도윤B, 박철수B, 오선록, 박광진, 김경은E, 정준기C, 홍성일A, 정재성A, 안정호D

— 광주채플
```

A조 차례에는 조 이름과 명단만 교체합니다(임수만, 최성계, 김호기, 김준영H, 김병수C, 장쾌남, 김대연A, 김중백, 김성철E, 이경모, 문형식).
