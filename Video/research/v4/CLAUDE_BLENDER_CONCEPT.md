# 벚꽃 단편 v4 구상안: Blender 30초 리메이크, 잠깐만요!

작성: Claude Code (2026-09-07). 제작 담당: Astra (Blender, computer use). 승인: 교수님.
상태: 구상 단계. 영상은 아직 없다. 개념 검증 렌더 1장과 그 생성 스크립트만 있다.

## 0. 목적 상기

- 홈페이지 Research 카드의 벚꽃 단편은 Nano Energy 2026 논문(벚꽃잎 TENG 제스처 인식, DOI 10.1016/j.nanoen.2025.111687)을 30초 안에 기억에 남게 하고 논문 보기 클릭을 유도하는 것이 목적이다.
- v3(잠깐만요!, Gemini/Flow 생성 애니메이션)로 방향은 확정됐다: 성인 캐릭터, 꽃잎을 구출하는 연구원과 쓸어버리는 미화원의 코미디, 화면 밖 하단 패널 자막, 과학 표현 락.
- 남은 문제는 품질이다. 생성 영상은 컷마다 인물과 소품이 흔들리고, 카메라와 타이밍을 프레임 단위로 통제할 수 없으며, 720p다. Blender는 정확히 그 반대다: 모든 프레임이 결정론적이고, 물리 시뮬레이션과 매크로 촬영이 강점이고, 1080p 이상이 공짜다.
- 따라서 v4는 이야기를 바꾸는 작업이 아니라, 같은 이야기를 Blender가 가장 잘하는 방식으로 다시 찍는 작업이다.

## 1. 한 줄 콘셉트

빗자루에 쓸려 가던 벚꽃잎 한 장이 센서의 한 층이 되어 손끝의 탭을 신호로 바꾼다. 카메라는 시작부터 끝까지 꽃잎의 눈높이에 있다.

## 2. 30초 안에 흥미를 잡아당기는 장치 7개

시청자는 클릭 후 3초 안에 계속 볼지 결정한다. 아래 장치는 모두 초 단위로 박혀 있고, 샷 리스트(4절)와 1:1로 대응한다.

| 1.5 | 패턴 인터럽트 | 빗자루가 렌즈로 돌진해 그 정적을 깨뜨린다. 거친 쓸림 소리가 첫 큰 소리다. 놓았던 마음이 놀라면 시선은 고정된다. |

공통 규칙: 죽은 프레임 0. 자막이 뜨는 동안에도 화면은 계속 움직인다. 같은 장치를 두 번 쓰지 않는다.

## 3. Blender 전략: 얼굴을 보여주지 않는다

v3의 매력은 인물의 얼굴 연기가 아니라 상황의 과잉이었다. Blender에서 얼굴 있는 캐릭터 애니메이션은 리깅, 표정, 립싱크, 언캐니 밸리까지 위험이 가장 큰 영역이고, 에이전트 제작에서는 더 그렇다. 그래서 v4는 인물을 손과 사물로만 연기한다.

- 연구원 도윤: 파란 니트릴 장갑 + 흰 랩코트 소매. 캠퍼스에서도 장갑을 끼고 있다는 설정 자체가 개그다(언제든 시료를 채집할 준비).
- 미화원 성만: 빨간 점박이 코팅장갑 + 회색 작업복 소매 + 작업화 + 장대 빗자루 + 긴 손잡이 쓰레받기. 한국 캠퍼스라면 누구나 알아보는 소품이다.
- 두 종류의 장갑이 두 인물을 대신한다. 피부 셰이더가 필요 없고, 손 리그도 손가락 포즈 몇 개면 충분하다.
- 카메라가 연기한다. 다이빙은 프레임 밖에서 날아드는 팔과 흔들리는 카메라로, 절규와 됐다!는 목소리로, 90도 인사는 두 손으로 공손히 받는 동작으로 표현한다.
- 외부 로케이션은 세 컷(1, 2, 3~5)뿐이고 모두 지면 매크로라서 벚나무를 정교하게 만들 필요가 없다. 배경은 분홍 보케로 처리한다.

만약 교수님이 얼굴 있는 인물을 원하시면 10절의 대안 B를 쓴다.

## 6. 사운드 설계

- 템포 120 BPM(1박 0.5초). 탭 소리와 층 닫힘 소리를 박자에 올려 음악의 일부로 만든다. 한 번 탭 16.5초, 두 번 탭 18.5초와 18.75초.
- 0~1.5초: 바람과 피아노 한 음만. 첫 큰 소리는 1.5초의 빗자루다. 대비가 훅이다.
- 2.8~4.0초 슬로모: 저역 스웰과 늘어진 휘익, 그 다음 정적.
- 5.6~10초: 드문 피치카토가 시작되고 지퍼 소리로 장면이 바뀐다.
- 10~14초: 피치카토가 리듬을 갖고, 클릭 4회가 박자에 붙는다.
- 14~16.5초: 한 음으로 멈춰 기대를 만든다.
- 16.5~21초: 삡 소리가 음정을 가진다. 두 번째 탭에서 화음이 해소된다.
- 21~24.5초: 공기 같은 패드와 유리질 아르페지오.
- 24.5~30초: 문 끼익, 코믹 바순, 해소, 페이드.
- 목소리 잠깐만요!, 이거… 최상급이에요., 됐다!는 연구실 구성원이 직접 녹음하는 것을 권한다. 합성 음성보다 웃음이 진짜다.
- 효과음은 CC0 라이브러리(freesound 등)에서, 음악은 라이선스가 명확한 트랙 또는 직접 제작. 최종 라우드니스는 v3와 같이 -16 LUFS 근처, true peak -1 dBTP 이하.

## 7. Blender 제작 설계도

### 7.1 공통 사양

- Blender 4.5 LTS 이상(개념 검증은 bpy 5.0.1로 수행). 씬은 가능하면 Python(bpy) 스크립트로 생성해 저장소에 남긴다. GUI는 확인과 미세 조정에 쓴다. v3가 edit-plan.json으로 소스 범위를 기록한 것과 같은 재현성 원칙이다.
- 해상도 1920×1080, 24 fps, 정확히 720프레임. 시안은 960×540.
- 렌더 엔진 이원화: 컷 1, 5(그리고 원하면 7)는 Cycles(반투명 꽃잎, 매크로 심도). 나머지는 EEVEE(속도, 블룸, 볼륨). 두 엔진의 색 관리는 AgX로 통일.
- 카메라 모션 블러는 실시간 컷에서 켜고, 슬로모 구간에서만 끈다. 심도는 매크로 컷에서 f/4 내외.
- 컴포지터: 미세한 필름 그레인, 비네트, 실험실 컷 블룸. 화면 안 글자는 어떤 경로로도 넣지 않는다.

### 7.2 에셋 목록

| 에셋 | 제작 방법 | 참고 |
|---|---|---|
| 꽃잎 | 매개변수 격자 메시(길이 14 mm, 폭 11 mm, 끝 갈라짐 2.2 mm), 폭 방향 오목함 | 개념 검증 스크립트에 구현 완료 |
| 꽃잎 재질 | Principled + Translucent 혼합, 기부 분홍 → 끝 흰색 그라데이션, Wave 잎맥 + 범프, Object Info Random으로 개체별 색 편차 | 개념 검증 스크립트에 구현 완료 |
| 꽃잎 산포 | 지오메트리 노드: Distribute Points on Faces → Instance on Points, 무작위 회전·크기. 지면용(빽빽)과 공중 층용(드문드문) 두 종 | 개념 검증 스크립트에 구현 완료 |
| 빗자루 | 손잡이 실린더 + 짚 다발(커브 700가닥 베벨). 리지드 바디 충돌용 단순 블록 별도 | 짚 다발은 개념 검증 스크립트에 구현 완료 |
| 긴 손잡이 쓰레받기 | 하드서피스 모델링, 아연도금 금속 재질 | v3 소품 규격 유지 |
| 장갑 손 2종 | MakeHuman 또는 Blender Studio Human Base Meshes(CC0) 팔 부분 + Rigify. 파란 니트릴(광택, 얇은 반투명), 점박이 코팅장갑(패브릭 + Voronoi 점 마스크) | 얼굴, 몸통 불필요 |
| 소매 | 실린더 커프 + 클로스 시뮬(어깨 핀, 바람 필드) | 컷 3에서만 격렬히 움직임 |
| 소자 | PET 필름, 전극, 꽃잎 층, 스페이서, 상부 필름의 5층 스택(약 3×3 cm) + 리드 2줄. 단면 컷어웨이 모델 별도 | 재료명은 화면에 쓰지 않음 |
| 계측기와 화면 | 벤치톱 박스 + 화면 평면. 화면은 파형 이미지 시퀀스(720장, Python으로 생성, 글자 없음). 전원선은 콘센트까지 보이게 | 과학 락: 소자가 화면을 켜지 않음 |
| 실험실 | 검은 벤치, 링라이트, 창(꽃잎 유입), 문(라이트 스윕) | 사이트 히어로와 같은 어두운 바탕에 파란 액센트(#1E3AFF, #00E6C6) |
| 야외 | 지면(돌 포장 텍스처, Poly Haven CC0), 분홍 보케 발광 구, 낮은 역광 태양 | 나무 모델 불필요 |

### 7.3 파형 표현

- 탭 한 번은 접촉과 분리에 해당하는 양음 이상성 펄스(위로 한 번, 아래로 한 번)로 그린다. 실제 TENG 출력의 형태와 같아서 전문가가 봐도 어색하지 않다.
- 두 번 탭은 같은 펄스 2개가 0.25초 간격으로 나타난다.
- 분류 시각화(컷 11)는 두 점 무리와 경계면만 쓴다. 정확도 숫자, 알고리즘 이름, 라벨 글자는 넣지 않고 자막이 설명한다.

### 7.4 제작 순서 (승인 지점 2개)

1. 애니매틱: 회색 박스와 임시 음성으로 14컷 타이밍을 EEVEE 저해상도로 렌더하고 자막 큐를 얹어 30초를 확인한다. 승인 지점 1(교수님).
2. 히어로 에셋: 꽃잎, 장갑 손 2종, 빗자루, 쓰레받기, 소자 스택.
3. 히어로 컷 우선 제작: 컷 3(포스터), 컷 5(뷔티샷), 컷 7(조립), 컷 9~10(탭). 이 네 컷의 스틸을 모아 승인 지점 2.
4. 나머지 컷 제작과 컴포지팅.
5. 음성 녹음, 음악, 효과음, 믹스(-16 LUFS).
6. 최종 렌더(PNG 시퀀스) → FFmpeg 조립 → 포스터 → VTT → edit-plan.json.
7. QA(8절)와 홈페이지 통합(9절).

### 7.5 렌더 시간 감각

- 개념 검증: 1280×720, Cycles CPU 4코어(GPU 없음), 128 샘플, 적응 샘플링과 디노이즈 포함으로 프레임 1장에 약 3분 40초가 걸렸다(poc/render.log). GPU가 있는 워크스테이션이면 같은 프레임이 1분 안쪽이다.
- Cycles 컷(1, 5, 7 합계 약 230프레임)은 GPU에서 프레임당 30~60초를 가정하면 2~4시간. EEVEE 컷(약 490프레임)은 프레임당 3~6초로 1시간 이내.
- 작업 시간은 숙련자 기준 3~5일을 가정한다. 에이전트의 처리량은 미지수이므로 승인 지점 1에서 다시 추정한다.

## 8. 과학 표현 락 (v2.1 락과 v3 검수를 그대로 계승)

- 꽃잎은 소자의 한 층이다. 꽃잎이 전기를 만들어 실험실이나 화면을 켠다고 읽히는 컷은 없다.
- 신호는 접촉과 분리에서 나온다. 컷 9의 단면이 이것만 보여준다.
- 머신러닝은 한 번과 두 번 탭을 구별한다. 스와이프, 원 동작, 감정 인식 같은 확장 주장은 넣지 않는다.
- 계측기와 화면은 별도 전원을 쓴다. 전원선을 콘센트까지 보여준다.
- 화면 안 글자 0. 파형만 예외. 성능 수치와 공정 세부는 논문 링크로 이관한다.
- 소자 제작 컷은 연출이며 실험 촬영물이 아니다. 홈페이지 노트에 3D 연출 영상이라고 표기한다.

## 9. 홈페이지 통합 사양

- 산출물: cherry-blender-30s.mp4(30.000초, 1920×1080, 24 fps CFR, H.264 CRF 20, yuv420p, AAC 48 kHz 스테레오, faststart), cherry-blender-30s.jpg(컷 3 포스터, 약 3.4초 프레임), cherry-blender-30s.ko.vtt와 .en.vtt, edit-plan.json.

- 자막은 기존 하단 패널이 처리하므로 영상에 글자를 굽지 않는다.
- 검증: 완전 디코드, 720프레임, tests/research-captions.cjs 정상과 reduced-motion 두 모드 통과, 390 px 모바일, 한영 전환, 라우드니스 측정값 기록.

## 10. 대안 훅 (교수님 선택용, 각 한 단락)

- 대안 A, 시네마틱 무코미디: 벚나무 아래 꽃잎 폭풍이 공중에서 완전히 멈추고 카메라가 그 사이를 궤도로 통과한다. 한 장만 빛나며 소자로 이어지고 탭과 스파이크로 끝난다. Blender 시연으로는 가장 화려하지만 v3에서 확정된 웃음이 사라진다. 국제 학회 상영용 변주로 적합하다.
- 대안 B, 얼굴 있는 인물: Blender Studio가 CC-BY로 공개한 리그(Rain, Snow, Sprite Fright 캐릭터)나 MakeHuman 인물에 Mixamo 달리기·점프 모션을 리타깃해 v3의 전신 다이빙을 재현한다. 얼굴은 역광 실루엣과 모션 블러로 숨기고 손과 소품은 본안과 같게 한다. 제작 위험이 2~3배 커지므로 본안 승인 후 추가 컷으로만 검토한다.

## 11. 교수님 결정이 필요한 항목

1. 얼굴 없는 손과 사물 연출로 진행할지(권장), 대안 B를 열어둘지.
2. 최종 해상도 1080p(권장, 다른 네 편과 동일)인지 720p인지.
3. 세 마디 목소리를 구성원이 녹음할지, 합성 음성을 쓸지.
4. 음악을 라이선스 트랙으로 할지 직접 만들지.

## 12. 개념 검증 (이 커밋에 포함)

- blender/petal_ground_poc.py: 빈 씬에서 꽃잎 메시, 반투명 재질, 지오메트리 노드 산포(지면과 공중), 짚 빗자루(모션 블러), 역광 태양, 보케 발광 구, 지면 12 mm 높이의 매크로 카메라를 만들고 컷 1~2 프레임을 Cycles로 렌더한다. Blender 없이 pip bpy만으로도 실행된다.
- poc/petal-ground-poc.png: 그 결과 1장(1280×720, 128 샘플, CPU). 꽃잎의 끝 갈라짐, 기부 분홍에서 끝 흰색으로 가는 그라데이션, 지면 카펫의 심도 흐림, 왼쪽에서 들어오는 빗자루, 분홍 보케가 모두 스크립트 한 파일로 재현된다는 증거다.
- 아직 검증하지 않은 것: 장갑 손 리그, 소매 클로스, 리지드 바디 낚아채기, 파형 이미지 시퀀스. 제작 순서 1~2단계에서 Astra가 같은 방식(스크립트 + 스틸)으로 검증한다.
- storyboard.html: 14컷 스케치, 30초 타임라인, 사이트와 같은 하단 자막 패널로 큐 타이밍을 재생해 보는 단일 HTML 스토리보드.
