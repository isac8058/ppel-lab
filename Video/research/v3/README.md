# 벚꽃 액션 쇼츠 — 잠깐만요!

상태: **30초 실제 영상 편집·로컬 재생/자막 검증 완료. Claude 최종 독립 검토 완료. 홈페이지 게시 확인 중.**

성인 연구원이 “잠깐만요!”를 외치며 청소부가 쓸던 벚꽃잎을 수평 다이빙으로 낚아챈다. 꽃잎 감정, 캠퍼스 추격, 센서 실험, 승리 춤, 청소부의 꽃잎 배달로 이어지는 코믹 연구 홍보 영상이다. 이전 로맨스 버전 장면을 재사용하지 않았다.

## 실제 완성본

- `cherry-action-30s.mp4`: 30.000초, 1280×720, 24fps, H.264/AAC 48kHz stereo, 약10.45MB, faststart.
- `cherry-action-30s.jpg`: 실제 다이빙 프레임의 포스터.
- `cherry-action-30s.ko.vtt`, `.en.vtt`: 실제 대사/동작에 맞춘 한영 자막. 홈페이지의 영상 바깥 하단 패널에 표시하며 영상에 글자를 굽지 않는다.
- `edit-plan.json`: 정확한 소스 범위, 컷, 자막, 출처/검수 상태.

| 완성본 시간 | 실제 내용 |
| --- | --- |
| 0–4.5초 | 빗자루 앞 외침 → 수평 다이빙 → 꽃잎을 지키며 바닥 슬라이드 |
| 4.5–10초 | 꽃잎 감정 → 질주 → 날아가는 꽃잎에 경악 |
| 10–15초 | 캠퍼스 계단 추격 → 담장 넘기와 캐치 |
| 15–19초 | 꽃잎 층 소자 제작과 단일 탭의 계측 |
| 19–25초 | 다른 앵글의 이중 탭 → 우스꽝스러운 승리 춤 |
| 25–28초 | 청소부의 꽃잎 배달 → 90도 인사 → 둘이 시료 선별 |
| 28–29초 | 계속 움직이는 선별 장면 옆에 논문 출처 카드 |
| 29–30초 | 한 초짜리 논문 출처 엔드 카드 |

움직이는 고유 영상 29초와 논문 출처 카드 1초를 연결했다. 반응 장면을 멈추거나 과거 장면을 반복하여 길이를 채우지 않았다. 소스 속 19초 이후 인물 복제 오류는 정확한 컷 경계에서 제거했다.

## 출처와 제작

- `CLAUDE_ACTION_SHORT.md`: 실제 Claude CLI가 사용자 기억을 바탕으로 새로 작성한 대본. 사용자가 기억한 옛 쇼츠 원본을 복구한 것은 아니다.
- 착수 검토: 실제 `claude-fable-5-1`, 정상 종료0, 검증된 응답 모델 일치. 외부 계측기 전원, 구도 변화, 생성 글자 제거 의견을 반영했다. 제공 텍스트 검토이며 Claude가 영상을 직접 봤다고 표현하지 않는다.
- `cherry-action-opening.png`: 직접 생성한 성인 애니메이션 캐릭터/스타일 참고 이미지. `opening-image-prompt.txt`에 지시 보존.
- `clip-1.mp4`: Gemini Omni의 실제 10초 동영상. [제작 대화](https://gemini.google.com/app/add93ad0fc546ddd).
- `clip-2.mp4`: Gemini Omni의 약20.02초 연장본. 0–10초는 앞 영상 반복이므로 최종본에 다시 넣지 않았고, 10–19초만 사용. 19–20초 인물 복제 오류를 제거. [20초 원본 미리보기](https://share.gemini.google/8MzCoGedBMMJ).
- `clip-3.mp4`: Google Flow Omni 1.1 Flash의 새10초 영상. 기존 Plus 포함 크레딧15개 사용, 구매/추가 구독 없음. 2026-09-06 생성.
- `clip-*-prompt.txt`: 원본 생성 지시. 마지막 Flow 요청은 같은 캐릭터, 연구실, 이중 탭/춤/청소부 배달/선별, 글자 없음, 외부 계측 전원을 다시 명시했다.
- `lab-reference.png`: clip2의18.5초 장치 참고 프레임.
- `scripts/assemble-cherry-action.cjs`: 검수된 실제 구간만 편집하고 정확한 논문 카드/자막을 만든다. Node의 `@napi-rs/canvas`와 FFmpeg가 필요하다.

## 과학 표현과 한계

벚꽃잎을 층으로 넣어 제작한 소자의 접촉·분리 신호를 머신러닝으로 분석하여 단일·이중 탭을 분류한 연구다. 외부 측정기와 모니터는 별도 전원을 사용한다. 흩어진 꽃잎 자체가 연구실을 켜거나, 스와이프·원동작·감정을 분류한다는 주장은 넣지 않았다.

논문: *Self-powered gesture recognition using a sustainable and thermally stable cherry blossom triboelectric nanogenerator*, Nano Energy (2026), [DOI 10.1016/j.nanoen.2025.111687](https://doi.org/10.1016/j.nanoen.2025.111687).

15–19초의 소자 제작 매크로도 AI 연출 영상이며 실제 실험 촬영물이 아니다. 홈페이지에 한영으로 AI 연출 안내를 표시한다. 그 외 화면은 성인 애니메이션이다.

## 검증

- 원본2fps/완성본1fps 프레임 시트, 주요 컷 경계, 출력30초 및 전체 디코드 확인.
- 로컬 faster-whisper/base ASR로 첫 “잠깐만요!”와 “이거 최상급이에요” 확인. 마지막 원본의 '됐다!'는 ASR에서도 확인됐지만 전체 편집본 ASR은 해당 한마디를 다르게 인식했다. 자막은 대본과 원본 전사를 따른다. ASR은 사람의 직접 청취와 구분한다.
- `tests/research-captions.cjs`: 정상/reduced-motion 두 모드 모두 통과. 다섯 영상의 지연 로드·30초 길이·자막 시킹, 한영 전환, 영상 밖 하단 자막, 전체화면,390px모바일 가로넘침 없음, 기존 히어로 애니메이션 유지 확인.
- 홈페이지 변경은 벚꽃 영상 한 편과 제목/연출 안내/출처 연결에 한정. 나머지 네 영상의 새 애니메이션 제작 완료를 의미하지 않는다.

최종 독립 검토: 실제 Claude `claude-fable-5-1`, 정상 종료0, 응답 모델 검증 일치. 제공 텍스트 기준 게시 전 필수 수정 없음. 검토 후 기록 상태/제외 구간 문구를 정리하고, 두 도구에서 생성한 오디오를 소스별2회 분석·정규화했다. 최종 구간별 통합 음량은 -14.87 / -16.11 / -18.04 LUFS, true peak는 모두 -1.0dBTP 미만이며 전체 영상·음성 디코드 오류가 없다.

단일·이중 탭 Random Forest 분류, DOI 및2026년2월 게재는 [전북대 연구자 포털](https://pure.jbnu.ac.kr/en/publications/self-powered-gesture-recognition-using-a-sustainable-and-thermall/)과 [출판사 초록](https://www.sciencedirect.com/science/article/pii/S2211285525010468)에서 재확인했다.
